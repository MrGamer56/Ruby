# Ruby

This repo contains two standalone static sites, each self-contained in its own folder:

- **`will-you-go-out-with-me/`** — the current site: a mobile-first, 5-screen
  "will you go out with me" experience (envelope → letter → memories
  carousel → anticipation → the question). Plain HTML/CSS/JS, no build step.
  See that folder's own `README.md` for details on customizing it.

- **`valentine-unfold/`** — the original Rocket.new-generated "Valentine
  Unfold" template, restored as it was before the rewrite.

Each folder has its own `index.html`, `css/`, `public/`, etc. and can be
deployed independently as a static site.
